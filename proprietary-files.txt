# partition of the firmware installed on the device.
# Reference firmware: EvolutionX 16.0 (11.10, 2026-08-07) for spes,
# vendor security patch 2026-05-01 (QTI Keymaster 4.1 / Gatekeeper 1.0).
# The same file set exists in stock MIUI 14 V816.0.8.0.TGCMIXM, except that
# MIUI ships boot control 1.1 instead of 1.2.
#
# Format: <source path in vendor partition>[:<destination under recovery/root>]
# Extract with: tools/extract-files.sh [--adb | --dump <dir>]
#
# Destinations follow device/qcom/twrp-common: on Android 10+ trees the
# decryption services are executed from /system/bin in recovery.
